SPATIUMGEO PROFESSIONAL SITE

Esta versión es HTML + CSS + JS puro.
No necesitas React, npm ni instalar nada.

PARA VERLA:
1. Descomprime el ZIP.
2. Doble clic en index.html.

PARA SUBIR A VERCEL:
1. Entra en Vercel.
2. Add New Project.
3. Importa/sube esta carpeta con:
   - index.html
   - assets/
4. Framework preset: Other.
5. Deploy.
6. En Settings > Domains añade:
   spatiumgeo.com
