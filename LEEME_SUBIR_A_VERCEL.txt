WEB SPATIUMGEO LISTA PARA VERCEL Y GITHUB

1) Sube todo el contenido de esta carpeta a un repositorio de GitHub.
2) Entra en Vercel y selecciona "Add New Project".
3) Importa el repositorio.
4) No hace falta comando de build: es una web estática HTML/CSS/JS.
5) Output directory: .
6) Publica.

Incluye:
- index.html
- assets/
- robots.txt
- sitemap.xml
- manifest.webmanifest
- vercel.json

Importante:
- No hay enlaces a LinkedIn ni redes sociales.
- La SEO de Valencia / Comunidad Valenciana está en metadatos, no como contenido visible principal.
