# SPATIUMGEO - web lista para Vercel y GitHub

Versión revisada: diseño futurista/profesional, imágenes realzadas, páginas legales redactadas sin formato de tabla, archivos en la raíz del proyecto, rutas relativas y sin enlaces externos de redes sociales.

## Subir a GitHub
1. Descomprime este ZIP.
2. Sube todos los archivos y carpetas a la raíz del repositorio: `index.html`, `assets/`, `robots.txt`, `sitemap.xml`, `manifest.webmanifest`, `vercel.json`.
3. Haz commit y push.

## Publicar en Vercel
1. Entra en Vercel y pulsa **Add New > Project**.
2. Importa el repositorio.
3. Framework Preset: **Other** o **Static Site**.
4. Build command: vacío.
5. Output directory: vacío o `.`.
6. Deploy.

## Prueba local
Puedes abrir `index.html` directamente o lanzar:

```bash
python3 -m http.server 3000
```

La web no depende de librerías externas ni de redes sociales.
